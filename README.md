## Project Description

The Employee Management System is a Java application developed to demonstrate the implementation of Object-Oriented Programming (OOP) concepts.

The project represents an employee management system in which employee information can be entered, processed, and displayed. It focuses on organizing employee data using classes, constructors, attributes, and methods.

The system also demonstrates salary calculation by calculating the net salary after a 20% deduction from the basic salary.

## Features

- Enter employee information through the console.
- Store employee details, including name, address, department, ID, phone number, and basic salary.
- Calculate the net salary after a 20% deduction.
- Display employee information and salary details.
- Apply fundamental Java programming and OOP concepts.

## How to Run

1. Install the Java Development Kit (JDK).
2. Open the project in a Java IDE, such as IntelliJ IDEA, Eclipse, or Visual Studio Code.
3. Make sure `Employee.java` and `Main.java` are configured correctly.
4. Run the `Main.java` file.
5. Enter the requested employee information in the console.
6. View the employee details and calculated net salary.

## Salary Calculation

The net salary is calculated by deducting 20% from the basic salary.

**Formula:**

```text
Net Salary = Basic Salary - (Basic Salary × 0.20)
```

**Example:**

```text
Basic Salary: 10000
Net Salary: 8000
```
